# Ingestion Module

Document and knowledge ingestion pipelines.

## Components (Phase 3-5)

- `pdf_parser.py` - PyMuPDF digital PDF extraction
- `ocr_processor.py` - PaddleOCR for scanned documents
- `docx_parser.py` - python-docx Word document parsing
- `knowledge_fetcher.py` - Trusted source content fetching
- `content_cleaner.py` - Content cleaning and normalization
