# Workers Module

Celery task definitions for async processing.

## Tasks (Phase 1+)

- `celery_app.py` - Celery application configuration
- `ping.py` - Trivial ping task (Phase 1)
- `document_tasks.py` - Document processing tasks (Phase 3)
- `embedding_tasks.py` - Embedding generation tasks (Phase 5)
- `knowledge_tasks.py` - Knowledge ingestion tasks (Phase 5)
