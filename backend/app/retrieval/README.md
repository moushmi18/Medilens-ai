# Retrieval Module

Hybrid retrieval system for RAG pipeline.

## Components (Phase 6-7)

- `vector_search.py` - Dense vector retrieval
- `bm25_search.py` - Sparse keyword retrieval
- `hybrid_search.py` - Combined retrieval with RRF
- `reranker.py` - BGE cross-encoder reranking
- `filters.py` - Metadata filtering utilities
