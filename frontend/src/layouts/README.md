# Layouts

Layout wrapper components for different page types.

## Layouts

- `MainLayout.tsx` - Authenticated pages with sidebar navigation
- `AuthLayout.tsx` - Login/register pages (centered card layout)

## Design System

- Primary: Navy (#1e3a5f)
- Secondary: Teal (#0d9488)
- Accent: Soft green (#22c55e)
- Background: White/very light grey (#f8fafc)
- Cards: Rounded corners, subtle shadows
- Responsive: Desktop, tablet, mobile
