# Components

Reusable React components for MediLens AI.

## Structure

Components will be organized by feature:
- `ui/` - Base UI components (buttons, inputs, cards)
- `layout/` - Layout components (header, sidebar, footer)
- `reports/` - Report-related components
- `chat/` - Chat interface components
- `dashboard/` - Dashboard widgets

## Guidelines

- All components use TypeScript
- Props are defined with interfaces
- Components are styled with Tailwind CSS
- Complex components have their own directory with index.tsx
