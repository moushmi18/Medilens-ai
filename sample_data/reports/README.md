# Synthetic Medical Reports

This folder contains synthetic medical reports for testing MediLens AI.

**IMPORTANT**: These are completely synthetic/fictional reports created for testing purposes.
They do NOT contain real patient data.

## Files

### Digital PDF Reports
- `cbc_report_2024_01.pdf` - Complete Blood Count from January 2024
- `cbc_report_2024_06.pdf` - Complete Blood Count from June 2024 (for comparison)
- `lipid_panel_2024.pdf` - Lipid panel results

### Scanned Image Reports
- `metabolic_panel_scan.png` - Scanned metabolic panel (tests OCR)

### DOCX Reports
- `thyroid_panel.docx` - Thyroid function tests

## Report Contents

All reports use the fictional patient "Test Patient" and contain realistic but
completely synthetic lab values for testing extraction and comparison features.
